# Upstream CLI Mapping

## Contract boundary

The Node CLI at `vendor/mikuproject/scripts/mikuproject-cli.mjs` is the source
of truth for every command listed as shared below. Java must preserve the
command name, options, defaults, stdin/stdout behavior, diagnostics, exit code,
and generated artifact contract unless a difference is explicitly documented
as a Java extension.

The Java `--help` output is intentionally not byte-identical to the Node help:
it also advertises the Java-only commands below. The shared-command entries and
their runtime behavior remain Node-compatible and must be covered by parity
tests.

## Shared Node and Java commands

- `ai spec`, `ai detect-kind`, `ai export project-overview`, `ai export task-edit`, `ai export phase-detail`, `ai export bundle`, and `ai validate-patch`
- `state from-draft`, `state summarize`, `state diff`, and `state apply-patch`
- `import xlsx`
- `export workbook-json`, `export xml`, and `export xlsx`
- `report wbs-xlsx`, `report daily-svg`, `report weekly-svg`, `report monthly-calendar-svg`, `report all`, `report wbs-markdown`, and `report mermaid`

## Java-only extensions

The following commands are Java operational extensions and are not required to
be present in the Node CLI:

- `state validate`, `state import`, and `state merge`
- `validate xml` and `validate xlsx`
- `merge xlsx`
- `report dir`
- `export xlsx` preserves the Java workbook layout's extended task, resource,
  and assignment columns. The shared `export workbook-json` command emits the
  Node workbook JSON projection instead.
- For a model with no usable project or task dates, `report daily-svg` and
  `report weekly-svg` retain the Java runtime's fallback timeline rendering.
  Node renders the same tasks as label-only rows. This legacy Java behavior is
  intentionally preserved and must not change the dated-fixture parity tests.

Keep extensions in the Java CLI help, README, and Java-focused tests. Do not
let their options or diagnostics alter the behavior of a shared command.

## Verification

- `MikuprojectNodeParityTest` verifies report-directory, report-bundle, and
  monthly-SVG ZIP bytes when `MIKUPROJECT_RUN_NODE_PARITY=true`.
- The same test compares Node and Java stdout, stderr, and exit codes for
  `state summarize`, `ai export bundle`, and `export workbook-json`, including
  JSON diagnostics where supported.
- Shared CLI tests must compare Node and Java stdout, stderr, exit code, and
  generated bytes for representative fixtures.
- Java extension tests remain in `MikuprojectCliTest` and must be identified as
  Java-only behavior.
